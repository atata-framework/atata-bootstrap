C#/.NET library containing a set of [Atata](https://github.com/atata-framework/atata) components for automated web testing integration with [Bootstrap Framework](https://getbootstrap.com/).

Works with Bootstrap components of version 3-5.

*The package targets .NET 8.0 and .NET Framework 4.6.2.*

**[What's new in v4.0.0](https://github.com/atata-framework/atata-bootstrap/releases/tag/v4.0.0)**

## Components

Namespace is `Atata.Bootstrap`.

- `BSModal`
- `BSNavbar`
- `BSDropdown`
- `BSDropdownToggle`
- `BSNavItem`
- `BSTab`
- `BSPill`
- `BSTabPane`
- `BSListGroup`
- `BSListGroupItem`

## Triggers

- `ClickTabOrPillAttribute`
